# Centralized Procurement 	System

## Overview

This centralized procurement System is a comprehensive enterprise desktop application developed in C# (.NET). It is designed to streamline and automate the procurement process, manage suppliers, and track inventory across various departments, specifically tailored to support restaurant and accounting operations. The system interfaces with a MySQL database to ensure reliable, centralized data storage.

## Modules

The application is organized into several key modules for modularity and maintainability:

- **Purchase Module**: Manages the creation, routing, and approval of purchase requests.
- **Accounting Module**: Handles financial tracking, cost centers, and final approvals.
- **Inventory Module**: Manages stock levels, tracks items, and oversees warehouse operations.
- **Restaurant Module**: Specific functionalities tailored for restaurant ordering and localized inventory.
- **Supplier Module**: Manages supplier information, catalogs, and performance.
- **User Management Module**: Handles user roles, permissions, and authentication.

## Technology Stack

- **Language**: C#
- **Framework**: .NET Framework
- **Database**: MySQL

## Prerequisites

- Visual Studio 2019/2022 (with .NET desktop development workload)
- MySQL Server
